# Security policy

Universal Transit Planner is pre-release software. Security fixes are applied
to the current `main` branch; older commits and generated builds are not
supported releases.

Please do not open a public issue for a suspected vulnerability. Use GitHub's
**Security → Report a vulnerability** workflow so maintainers can investigate
privately. Include the affected revision, a minimal reproduction, expected
impact and any suggested mitigation. Do not include credentials, access tokens
or personal data that are not necessary to reproduce the issue.

Ordinary bugs and data-quality problems belong in the public issue tracker.
