# Code of conduct

We want Universal Transit Planner to be a useful, welcoming project for people
working across software, transport, geography and public policy.

## Expected behaviour

- Be respectful and constructive, especially when correcting mistakes.
- Critique ideas and evidence rather than people.
- Make space for different levels of technical and domain experience.
- Protect private information and disclose conflicts of interest.
- Accept moderator decisions and help repair harm when problems occur.

## Unacceptable behaviour

Harassment, threats, discriminatory language, sexualized attention, deliberate
intimidation, doxxing, sustained disruption and retaliation are not welcome in
project spaces.

## Reporting and enforcement

Report ordinary conduct concerns privately to the maintainers through an
appropriate GitHub channel. If the report itself is sensitive, use a private
GitHub security advisory. Maintainers may edit or remove contributions, warn
participants, temporarily restrict participation or permanently exclude a
participant. Reports will be handled as confidentially as practical, while
recognizing that investigation may require sharing limited information.

This policy applies in the repository and in public spaces where someone is
representing the project.
